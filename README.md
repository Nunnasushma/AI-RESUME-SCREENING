# 🤖 AI Resume Screening System

AI Resume Screening System is a full-stack web application designed to analyze resumes and assist in candidate screening. The system uses AI/NLP-based processing to extract useful information from resumes and simplify the initial recruitment screening process.

## ✨ Features

- Upload resumes for analysis
- Extract relevant candidate information
- Identify candidate skills and qualifications
- AI/NLP-based resume analysis
- Simple and responsive user interface
- REST API-based frontend and backend communication
- Supports automated candidate screening
- Provides structured resume analysis results

## ⚙️ Installation and Setup

### 1. Clone the Repository

git clone https://github.com/Nunnasushma/AI-RESUME-SCREENING.git

cd AI-RESUME-SCREENING

### 2. Install Frontend Dependencies

cd frontend
npm install
npm run dev

### 3. Install Backend Dependencies

Open another terminal:

cd backend
npm install
npm start

### 4. Run the AI Service

Navigate to the AI service directory:

cd ai-service

Install the required Python dependencies and start the AI service according to the project configuration.
